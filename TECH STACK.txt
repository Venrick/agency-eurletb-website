# Tech Stack Report: EURL ETB Achouri Toufik Website

## Project Overview
A modern, multi-language corporate website for a construction company in Algeria, built with a **static-first architecture** emphasizing performance, accessibility, and RTL language support (EN, FR, AR).

---

## 1. Frontend Framework & Styling

### **Tailwind CSS (CDN)**
- **Version:** Latest (via `https://cdn.tailwindcss.com`)
- **Approach:** JIT (Just-In-Time) compilation via CDN, configured inline in `<script>` tag
- **Custom Theme:**
  - **Colors:** Navy (`#1e243c`), Navy Dark (`#0f1323`), Navy Card (`#1a2036`), Gold (`#c19f5d`), Light Gray (`#f4f4f2`)
  - **Fonts:** Barlow, Barlow Condensed, Lato
  - **Extended utilities:** Custom color variables, responsive breakpoints
- **Advantages:** Zero build step, instant CSS generation, responsive design out-of-the-box

### **Custom CSS**
- Inline `<style>` block with:
  - Blueprint grid pattern overlays (48px × 48px gold grid at 7% opacity)
  - Hero radial fade gradient (navy vignette effect)
  - Geometric corner decorations (120×120px borders)
  - RTL-specific layout rules (flipped borders, mirrored margins, reversed gradients)
  - GSAP animation keyframes
  - Phone number LTR isolation for Arabic pages
- **Philosophy:** Minimal, semantic, performance-conscious

---

## 2. JavaScript & Animation

### **GSAP (GreenSock Animation Platform)**
- **Version:** 3.12.2 (via CDN)
- **Plugins:** ScrollTrigger
- **Use Cases:**
  - Scroll-triggered fade-in animations (staggered entrance effects)
  - Section animations (hero, stats, portfolio cards)
  - Navbar collapse/expand on scroll
  - Modal slide-up animations
  - Timeline animations on the about page
- **Performance:** Hardware-accelerated, optimized for mobile

### **Vanilla JavaScript (No Framework)**
- **i18n Module** (`assets/js/i18n.js`):
  - 3-language dictionary (EN, FR, AR)
  - Client-side language switching with localStorage persistence
  - Dynamic `dir="rtl"` attribute toggling for Arabic
  - Injected language switcher UI (dropdown on mobile, buttons on desktop)
  - Dynamic meta tag updates (og:title, twitter:description)
  
- **Modal & Interaction Logic** (inline in HTML):
  - Companies section: pillar click handlers, modal open/close
  - Modal card cloning and templating
  - Escape key and backdrop click handlers
  - Image map fallback click detection
  - Navbar scroll-spy active link detection

- **DOM Manipulation:**
  - Zero jQuery; pure DOM APIs
  - Event delegation for dynamic elements
  - classList-based state management

---

## 3. Multi-Language & Internationalization

### **Dictionary Structure** (i18n.js)
```javascript
{
  en: { "nav.home": "Home", ... },
  fr: { "nav.home": "Accueil", ... },
  ar: { "nav.home": "الرئيسية", ... }
}
```

### **Language Switching Mechanism**
- **Query Param:** `?lang=fr` or `?lang=ar`
- **Storage:** localStorage (`etb_lang`)
- **DOM Attribute:** `<html lang="...">` + `<html dir="rtl">` for Arabic
- **Meta Updates:** OG and Twitter tags updated dynamically

### **RTL Handling**
- No hardcoded `ml-`/`mr-` or `text-left`/`text-right` classes
- CSS Grid and Flexbox natural mirroring via `dir="rtl"`
- Custom RTL fixes via i18n.js injected styles
- Phone number LTR isolation (`<span class="phone-ltr">`)

## 7. Performance & Best Practices

### **Core Web Vitals Optimized**
- **LCP (Largest Contentful Paint):** Hero image with 0.18 opacity overlay
- **FID (First Input Delay):** Vanilla JS (minimal framework overhead)
- **CLS (Cumulative Layout Shift):** Fixed navbar, predefined hero height

### **Accessibility**
- WCAG 2.1 Level AA compliance
- Semantic HTML (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- ARIA labels on buttons and interactive elements
- Image alt text on all assets
- Color contrast: Gold on navy passes WCAG AA (6:1+)

### **Responsive Design**
- **Breakpoints:** Mobile (375px), Tablet (768px), Desktop (1440px)
- **Tailwind Utilities:** `max-md:`, `md:max-lg:`, responsive grid, flexible spacing
- **Touch Targets:** 44px × 44px minimum on mobile

### **SEO**
- Open Graph meta tags (og:title, og:image, og:description)
- Twitter Card meta tags
- Canonical URLs
- Language tags (`hreflang` ready)
- Structured data ready (Company schema compatible)
